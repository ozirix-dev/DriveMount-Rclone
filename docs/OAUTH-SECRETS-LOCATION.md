# OAuth Secrets Location

`D:\OAuth-Rclone`-kansion sisalto kuuluu salaisuuksiin, ei projektirepoihin.

## Kanoninen sijainti

- `K:\platform\rclone\oauth-rclone`

## Mitä siellä pidetaan

- OAuth client JSON
- client ID -muistiot
- client secret -muistiot

## Periaate

- repoihin ei tallenneta itse salaisuuksia
- dokumentaatio voi kertoa sijainnin ja kayttotarkoituksen
- poistosiivous lahdepolusta tehdään vasta erillisella vahvistuksella
